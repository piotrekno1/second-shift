# SecondShift 0.1.0b12

This beta is the first on PyPI. Draft pull requests are now authored by the
account that publishes them, and each GitHub connection decides whether its
work names SecondShift. Setup is quieter, and `secondshift up` says which port
is taken.

## Install from PyPI

```bash
uv tool install --python 3.13 secondshift==0.1.0b12
secondshift up
```

The release workflow uploads the same tested wheel to PyPI with trusted
publishing, so no upload token is stored. The wheel stays on the GitHub release
too.

## Who GitHub work is from

- Draft pull request commits are authored by the account that pushes them. With
  the GitHub App that is the App's bot. With a personal access token it is the
  token's owner. Before, commits used a fixed `secondshift` noreply address,
  which GitHub credits to an unrelated account.
- The App's name comes from GitHub, not from
  `SECONDSHIFT_GITHUB_APP_SLUG`, so a renamed App keeps publishing.
- Each GitHub source connection has **Mention SecondShift** in its menu on
  **Connections**. It is on by default for the App and off for a personal
  token. When it is off, the branch is named after the job, and pull
  requests, issues and commits don't name SecondShift. See
  [Attribution](https://github.com/piotrekno1/second-shift/blob/main/docs/github-app.md#attribution).
- Existing token connections stop naming SecondShift until an owner turns the
  setting on.

## Setup

- While the Overview shows the setup checklist, the sidebar shows no notes.
  Afterwards Connections says "N to set up" for services never connected and
  "N failing" for broken ones.
- `secondshift up` checks the web, gateway and runner ports before it starts.
  When one is taken, it names the port and the setting that moves it. Before,
  it built everything and then said only that the runner stopped.
- In the model form, Enter picks the highlighted model. Before, it saved the
  form with no model chosen.

## Releases and security

- Each release, and a weekly schedule, deploys the published image with the
  production Compose file on a gVisor host and runs the full end-to-end test.
- GitHub Actions workflows are pinned by a lockfile and checked by zizmor.
- dnspython 2.9.2, opentelemetry-api 1.45.2 and Astro 7.4.7 clear four
  dependency advisories. None applied to how SecondShift uses them.
