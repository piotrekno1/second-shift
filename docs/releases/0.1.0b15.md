# SecondShift 0.1.0b15

This release fixes the container image. For what's new since beta 13, see
[0.1.0b14](https://github.com/piotrekno1/second-shift/blob/main/docs/releases/0.1.0b14.md).

## Upgrade from beta 14

- No manual steps and no migrations.
- If you run the container image with Compose, upgrade to this release. The
  beta 13 and beta 14 images stop on first start because they lack the
  default sandbox images file. A server set up before beta 13 keeps working,
  but upgrade it to this release, not to beta 13 or beta 14.
- If you installed with `pip` or run `secondshift up`, nothing changes for
  you. The package already had the file.

## Fixes

- The container image includes `secondshift/config/runner_images.env`,
  which first-run configuration reads.
